## Things I've built

**[Safe AI: Ingredient Risk Predictor](https://github.com/praveen4398/cosmetic_ingredient)**
Scans product ingredient images using OCR, then classifies each ingredient as safe / caution / harmful with AI-generated health explanations. Built with Tesseract, Sentence Transformers, and Gemini API.

**[Social Media Analysis — Reddit](https://github.com/praveen4398/Reddit_API)**
NLP pipeline that pulls and processes 100K+ Reddit posts for trend and sentiment analysis. Data stored in MongoDB. Built this as a big data analytics project.

**Medical Report Analyzer**
Full GenAI pipeline for analyzing lab reports — PDF/OCR ingestion, 50+ parameter rule engine, fine-tuned Phi-2 (QLoRA on MedQuAD), FAISS vector search, and Streamlit frontend with SQLite persistence.

**BEV Simulation Dataset**
Ran 10,000 parallel simulations in MATLAB/Simulink using `parsim` to generate an EV trip dataset for ML training. Involved a lot of signal extraction debugging and parallel worker handling.

**[Corpus Admin Dashboard](https://github.com/praveen4398/Corpus-admin)**
Streamlit admin panel with OTP-based login and FastAPI backend — built during my internship at Swecha.

**[VEDUKA Android App](https://github.com/praveen4398/Veduka)**
Android app with animated splash screen and swipeable intro in Java/XML.
